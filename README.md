# 🚀 Spring Boot Kickoff Project

This is a simple Spring Boot application created as part of the OMS Training Bootcamp.  
The project demonstrates basic Spring Boot concepts such as controllers, DTOs, services, repositories, and layered architecture.

---

## 📦 Tech Stack

- **Java 17+**
- **Spring Boot**
- **Spring Web**
- **Spring Data JPA**
- **Maven**
- **PostgreSQL**
